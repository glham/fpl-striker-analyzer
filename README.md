# FPL Player Analyzer

Static WebAssembly build of `striker_analyzer_app.py` from the fpl-fantasy repo — live at https://glham.github.io/fpl-striker-analyzer/

Compare any players: xG and chance quality, chance creation (xA_FPL), FPL points vs expected points, and defensive contributions, filterable by venue and opposition strength.

Data: Sofascore shot maps and player match stats (Premier League 2023-24 onward) and FPL match data (2025-26 onward).
